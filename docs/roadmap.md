# Roadmap

## Phase 1 — Prototype (this build)

Hindi/English UI, fixed interview, browser voice/text, demo pathways, deterministic matching, synthetic local sample data, action plan, follow-up, handoff, dashboard and PWA shell.

## Phase 2 — District pilot

Validate current active qualification packs and entry requirements; source district demand and training capacity; verify centre details/accessibility; add counsellor authentication, consent-reviewed pilot process, assisted CSC mode, Bhashini pipeline and outcome governance.

## Phase 3 — Scale

Add regional languages and dialect testing, production WhatsApp/IVR adapters, government integration through approved interfaces, monitored service-level targets and outcome-based model research only after representative, governed data exists.
